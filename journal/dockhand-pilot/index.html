Testing Dockhand before changing container management

A side-by-side pilot tested whether Dockhand could handle routine container investigation while the existing interface stayed in place.

Events: November 11, 2026Evidence: Dated pilot verification reportEntry date: November 24, 2026

The change on November 11 was an evaluation of Dockhand as a day-to-day container management interface. The practical question was whether it could replace the parts of Portainer used to investigate a service. The existing interface stayed in place during the evaluation, and the lab kept its Compose deployment files as the source for service configuration.

Check Recorded result What it supports
Compare container lists Dockhand and Docker reported the same 97 containers, including 72 running. Inventory matched at the time of the comparison.
Open a live log stream The report captured a working stream. An operator could watch a container’s logs during a check.
Compare resource readings Memory matched in the sample. CPU readings differed slightly between polls. The sampled readings were consistent enough for inspection.
Check application sign-in An unauthenticated inventory request returned HTTP 401 after native authentication was configured. That request was blocked without an application session.

The report also inspected the Docker socket’s bind mount. That check established the mount setting. The documented test did not demonstrate which Docker API operations the application could call. That authorization question matters before choosing a permanent management interface.

The report records the start of a planned observation period. It does not record the outcome of that period or a completed Portainer retirement.

Running the two tools in parallel made the change easier to assess. There was already a working interface available if the new one failed during the comparison. It also made the success criteria easier to state: the pilot demonstrated selected investigation tasks, while continued operation and any cutover required separate evidence.

Reading note

Historical results describe what the records showed at the time. They are not a live status check.
