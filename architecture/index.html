System design

Architecture, over time.

The lab changed platforms and tools. These simplified snapshots show the operating ideas without revealing private endpoints or presenting old diagrams as live status.

Earlier virtualized lab · February–March 2026

Legacy records describe Proxmox and LXC hosting services, with ZFS storage, applications, monitoring and several network designs under test. A component appearing in a summary means it was part of that documented stage; it does not prove every workflow passed.

Historical view

Compute and storage → network/ingress → applications → monitoring and backups. The February dashboard account includes a same-night failure after an initial success report.

Bare-metal transition · April–May 2026

An April 7 summary records retiring the earlier Proxmox iteration and initializing an Ubuntu host for native Docker workloads. The first summary names Ubuntu 25.10; later May documents name 26.04. The upgrade or reinstall path and data continuity remain unresolved.

Historical view

Ubuntu host → Docker services → direct host storage and network responsibilities. This is an architectural change, not proof of complete migration.

CyberBiota3 operating model · June–October 2026

Formal change results describe a container platform with ingress, applications, observability, scoped backup, and local AI experiments. Later operational records also document drift, incidents and bounded acceptance. Current topology requires a fresh check before a present-tense diagram is published.

Documented layers

Host/data; network/DNS/identity; containers and applications; observability; automation and local AI; backup/recovery. Each layer has a separate evidence and recovery question.

What connects the layers

For an application to be operated, its process must start, its route and authentication must work for the intended client, its data must persist, and failures must be observable. Backup claims require a restore scope and a receipt. A working integration can still be rolled back if its trust boundary is unacceptable.
